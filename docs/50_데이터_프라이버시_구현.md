## 1. 다이제스트 종단간 암호화 (E2EE) — 확정
맥락 다이제스트는 **자녀 폰에서 암호화되고 부모 폰에서만 복호**된다. 백엔드(digest-relay)는
암호문과 라우팅 토큰만 보며 평문을 복호할 수 없다(불변식 #1).

### 1.1 암호 스킴
- **키 합의**: X25519 ECDH (자녀측 *ephemeral* 키 ↔ 부모 *static* 공개키).
- **키 유도**: HKDF-SHA256 으로 세션 키 도출.
- **AEAD**: XChaCha20-Poly1305 (24바이트 논스, AAD 인증).
- **전방향 비밀성**: 다이제스트마다 1회용 ephemeral 송신키를 생성·폐기 → 발신자 추적·과거 노출 방지.

### 1.2 와이어 포맷 (`docs/40` §4 `POST /v1/digests`)
```
{ routing_token, ephemeral_pubkey, nonce, ciphertext, aad }
```
- `routing_token`: 부모 수신함 라우팅용 불투명 토큰(콘텐츠 아님).
- `ephemeral_pubkey`: 1회용 X25519 송신 공개키.
- `nonce`: XChaCha20-Poly1305 논스.
- `ciphertext`: 봉인된 다이제스트 본문.
- `aad`: 인증된 추가 데이터(스키마 버전·라우팅 메타 등 평문 메타).
> 코드 대응: `app.tofairy.child.digest.EncryptedDigest`.

### 1.3 키 보관·진본성
- 개인키는 **Android Keystore(가능 시 StrongBox)** 내부에만 존재. 어떤 엔드포인트로도 전송하지 않는다.
- 페어링 시 교환한 공개키의 진본성은 **기기 간 지문 대조**(화면에 표시되는 짧은 지문)로 확보. 서버는 신뢰 근거가 아니다.

### 1.6 서버측 보존
- digest-relay 는 암호문 + 라우팅 토큰만 **단기 보존**, 부모 `ack` 후 정리.

### 1.8 케이스 B(동일 기기)
- 자녀-부모가 같은 기기를 공유하는 케이스 B 에서는 네트워크 중계를 **건너뛰고** 로컬에서 직접 전달한다.

## 2. 로컬 저장 암호화 (예정)

(Jetpack Security `EncryptedFile`). 최종은 libsodium/Tink 로 정렬.

## 3. Ephemeral 처리 규약 (예정)
